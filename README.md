# FomoDesk

FomoDesk is a browser-only crypto paper-trading terminal.

- Starts with $100,000 virtual USD.
- Buy and sell orders are simulated locally.
- Prices are generated locally and move for practice.
- Positions, P&L, and trade history persist in localStorage.
- No wallet connection, exchange API, blockchain transaction, or real-money order execution is included.

Open `index.html` in a browser to use it.
